# Pacifica PHEV Real-World Cost Tracker

Static site prepared for GitHub Pages.

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example `pacifica-phev-tracker`.
2. Upload `index.html` to the root of the repository.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public Pages URL after deployment.

## Updating the tracker

Replace `index.html` with the newer version and commit the change. GitHub Pages will republish the site automatically.
